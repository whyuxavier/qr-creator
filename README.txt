Генератор QR-кодів — мінімалістична версія

Відкрийте index.html у браузері. Вставте посилання та натисніть «Згенерувати».
QR-код можна зберегти у PNG або показати на весь екран.

Кнопка i містить опис сайту та посилання на GitHub автора: https://github.com/whyuxavier
Для завантаження бібліотеки QRCode.js потрібен інтернет. QR-код генерується у браузері.
